Demo 4 result: both shapes removed. The single-column shape IS chosen, but the
plan walks the full index filtering by quarter, discarding 800 rows to find 20.
The composite shape is also chosen and reads the 20 rows directly. Both are
removed because this query shape is a DirectQuery pattern, and this report is
Import mode: the Bank Scorecard is answered from VertiPaq, not from PostgreSQL.
The no-index plan already returns in under 1 ms for the same shape, so the
write and vacuum cost is not justified even if the report were DirectQuery.
Reasoning is in findings.md section "Indexes".
